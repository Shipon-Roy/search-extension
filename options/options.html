How templates work

Put {value} anywhere in the URL, for example https://example.com/merchant?id={value}. With no placeholder, the cleaned value is appended to the end, for example https://example.com/parcel/ + ABC123.

ID keeps letters, digits, - and _. Phone normalizes Bangladeshi numbers such as +880 1712-345678 to 01712345678. Raw text only trims outer whitespace.
